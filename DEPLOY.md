# GitHub Pages deployment

1. Create a new GitHub repository (for example `chinmyee-portfolio`).
2. Upload the **contents of this folder** to the repository root (index.html must be at root).
3. Commit files to the `main` branch.
4. In Settings > Pages, select Deploy from a branch, main, /(root), then Save.
5. Visit https://YOURUSERNAME.github.io/chinmyee-portfolio/ after deployment completes.

Edit through GitHub's web editor or push updates to `main` to refresh the same URL.

Note: Public GitHub Pages content and source assets are publicly accessible. Check photos/screenshots for private information before publishing.
